# Política de Contratación 2027

## Fórmula
Contrataciones necesarias = MAX(0, min_headcount − FTE_proyectado + salidas_anuales)

| Variable | Descripción |
|---|---|
| min_headcount | Dotación mínima requerida por base y rol |
| FTE_proyectado | Dotación actual − rotación − ausentismo |
| salidas_anuales | Exits históricos proyectados para 2027 |

## Prioridades

| Prioridad | Condición | Acción |
|---|---|---|
| P1 URGENTE | Gap < -10 Y 10+ meses con gap | Iniciar proceso inmediatamente |
| P2 CRITICO | Gap < -5 O 6+ meses con gap | Incluir en próximo ciclo de selección |
| P3 PLANIFICAR | Gap < 0 | Planificar para Q3/Q4 2027 |
| P4 OK | Sin gap proyectado | Sin acción inmediata |

## Tiempo de cobertura
months_to_fill = avg_training_days / 22 días laborables

Ejemplo:
- Piloto Comandante: 30 días → 1.4 meses para estar operativo
- Agente Check-in: 3 días → 0.1 meses

## Supuestos
- FTE actual = snapshot diciembre 2024
- Rotación 2027 = promedio histórico 2022–2024
- Requerimientos mínimos estables en 2027
- No se modela crecimiento de flota ni nuevas rutas

## Escenarios
- Base: cubrir dotación mínima con rotación histórica promedio
- Estrés: cubrir dotación óptima con rotación alta en temporada
